# math-exam-coach

一个面向**高等数学应试**的 AI 辅导员技能（skill）。核心理念只有一句：**先让你自己做，再告诉你差在哪。**

适合：大学高数期末、考研数学（数一/数二/数三）、以及跟着课程同步学习。

## 它解决什么问题

大多数人学高数的失败模式不是"没看过"，而是：

- 看懂了讲解，考场上认不出题型；
- 错题记了"粗心"两个字，下次照错；
- 想得到但做不完。

这个技能针对这三点设计：

1. **题型识别优先**——内置题型库，按"题干长什么样"定位方法，而不是按章节从头讲。
2. **答案释放门控**——你卡住时先给三级提示，不直接给答案；但你明确要答案时立刻给（并留痕）。
3. **错题落成真实文件**——带日期的错题本 + 复习队列，按可复现性归因，连续限时做对才退役。

## 怎么用

安装后在对话里直接说需求即可，例如：

- "我要学反常积分判收敛性"
- "这道题不会：[题目]"
- "帮我复习"（会报出今天到期的错题）
- "批改一下"（配上手写照片或打字解答）
- "导出错题本"

技能不会一上来就讲——它会先给你一两道诊断题，看你卡在概念、识别还是计算，再决定怎么教。

## 五步法

```
① 诊断/检验 → ② 讲解 → ③ 练习（交错+限时） → ④ 答案对照与归因 → ⑤ 复习调度
```

其中两条容易被做错、也是本技能最强调的：

- **①的"诊断"和"检验"是同一个动作**——不先做题就开讲，等于浪费。
- **③→④ 的答案对照是必做步骤**，不是讲评。你得自己说"我原打算怎么做、实际该怎么做、差在哪"。

## 数据存在哪

所有个人数据存在**工作区**的 `study/` 目录（不在技能目录里，也不会进任何公开仓库）：

```
study/
├── 00-learner.md          你的偏好与水平档案
├── 错题本.md              按日期分组的人读视图
├── records/questions.md   唯一状态源（错题本从这里生成）
└── 导出/                  带日期的导出快照
```

用 RikkaHub 等带工作区的客户端时，文件可以在 App 内查看，也能从系统文件管理器里直接拷出来。

## 覆盖范围

- 极限与连续、导数与中值定理、不定/定积分、反常积分、微分方程
- 多元微分、二重/三重积分、曲线曲面积分、三大公式
- 数项级数、幂级数、傅里叶级数
- 空间解析几何与场论

有两条轨道：期末/同步（默认）与考研（含数一/二/三差异）。

## 不做什么

- 不替你考试、不押题、不承诺分数。
- 不生成"详细解答集"式输出（那正好抵消练习效果）。
- 不覆盖英语、物理、专业课。
- **不承诺后台定时提醒**——它只能在会话里报到期项；真正的定时提醒请用配套的 `time-planner` 技能或手机闹钟。

## 安装

把整个 `math-exam-coach` 目录（含 `SKILL.md`）放到客户端的技能目录下即可。目录名必须与 frontmatter 里的 `name` 一致。

## 配套

- `time-planner`：把复习任务与作息排成日程，并能把到期错题塞进时间表。
