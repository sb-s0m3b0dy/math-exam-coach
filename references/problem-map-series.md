# 题型库：数项级数、幂级数、傅里叶级数

## 级数-正项级数判敛

- **触发特征**：一般项 `u_n ≥ 0`，问收敛还是发散。
- **标准流程**（按选择顺序）：
  1. **必要条件**：`lim u_n ≠ 0` → 发散（先查这个，最省时间）。
  2. 含 `n!`、`a^n`、`n^n` → **比值判别法**（达朗贝尔）。
  3. 含 `n` 次方/根号整体 → **根值判别法**（柯西）。
  4. 形如 `1/n^p` 或与它同阶 → **比较判别法**（找等价无穷小定阶）。
  5. `u_n` 含递减因子（如 `1/(n ln n)`）→ **积分判别法**。
- **陷阱**：
  - **不先查一般项是否趋于 0**，上来就用比值法（浪费时间且有时判不出）。
  - 比值法结果为 1 时**不能说收敛**（失效，需换法）。
  - `p` 级数：`Σ1/n^p` 在 p>1 收敛、p≤1 发散。
  - 用比较法时**方向弄反**。
- **常考形式**：期末/考研必考客观题；数一数三都有。

## 级数-交错级数（莱布尼茨）

- **触发特征**：正负交替 `Σ(−1)^{n−1} u_n`，`u_n > 0`。
- **标准流程**：
  1. 验证 `u_n` 单调递减。
  2. 验证 `lim u_n = 0`。
  3. 两条都满足 → 收敛（可能只是**条件收敛**）。
  4. 再判别 `Σ|u_n|` 是否收敛来区分绝对/条件收敛。
- **陷阱**：
  - **只验 `lim u_n = 0`**（不够，必须单调）。
  - 把"收敛"与"绝对收敛"混。
- **常考形式**：期末/考研必考。

## 级数-任意项级数（绝对收敛）

- **触发特征**：一般项符号不确定。
- **标准流程**：
  1. 先看 `Σ|u_n|` 是否收敛 → 是则**绝对收敛**（由此原级数收敛）。
  2. 若 `Σ|u_n|` 发散，再看原级数是否条件收敛（莱布尼茨或其它）。
- **陷阱**：直接对原级数用比值法而不加绝对值（比值法只对正项级数）。
- **常考形式**：期末/考研。

## 级数-幂级数收敛半径与收敛域

- **触发特征**：`Σ a_n (x−x₀)^n`，问收敛半径、收敛域。
- **标准流程**：
  1. 用比值法或根值法求 `R`（系数比：`R = lim |a_n/a_{n+1}|`）。
  2. 收敛区间 `(x₀−R, x₀+R)`。
  3. **端点单独判断**（这是必做步骤，端点可能条件收敛/发散）。
  4. 写出收敛域。
- **陷阱**：
  - **忘记检查端点**（最高频失分点）。
  - 缺项级数（只有偶次项，如 `Σ x^{2n}/4^n`）**不能直接套系数比公式**，要令 `u_n` 用比值法。
  - 平移没处理（`x−x₀` 里的 `x₀`）。
- **常考形式**：期末/考研必考大题。

## 级数-幂级数展开

- **触发特征**：要求把函数展成幂级数（麦克劳林/泰勒）。
- **标准流程**：
  1. 记住五个基础展开：`e^x`、`sin x`、`cos x`、`ln(1+x)`、`1/(1−x)`（还有 `(1+x)^α`）。
  2. 通过**代换、求导、积分、四则运算**从基础展开导出。
  3. 写收敛域。
- **陷阱**：
  - 代换后**收敛域没跟着换**（如 `1/(1+x²)` 用 `x²` 代 `x`，得 `|x|<1`）。
  - 泰勒中心不是 0 时还套麦克劳林公式。
  - 展开式中 n 的起始值写错。
- **常考形式**：期末/考研高频。

## 级数-幂级数求和

- **触发特征**：给一个幂级数，要求和函数或某个数项级数的和。
- **标准流程**：
  1. 求收敛域。
  2. 设和函数 `S(x)`。
  3. **通过求导或积分把系数化简**：
     - 系数含 `n` → 求导。
     - 系数含 `1/(n+1)` 或 `1/n` → 积分。
     - 含 `n(n+1)` → 求两次导。
  4. 求和后再积分/求导回去，用初值定常数。
  5. 求数项级数和时，把 x 取特定值代入和函数。
- **陷阱**：
  - 求导/积分后**忘了积回去或导回去**。
  - 常数 C 由 `S(0)` 或端点值确定这一步漏掉。
  - 收敛域端点没验证。
- **常考形式**：期末/考研必考大题。
- **技巧**：先提取公因子使下标与指数对齐，是常见的第一步。

## 级数-傅里叶级数

- **触发特征**：周期函数展开、狄利克雷收敛定理。
- **标准流程**：
  1. 判断周期与奇偶（奇函数只有 sin 项，偶函数只有 cos 项——**用这个能省一半计算**）。
  2. 套系数公式：
     - `a₀ = (1/π)∫_{−π}^{π} f(x)dx`
     - `a_n = (1/π)∫_{−π}^{π} f(x)cos nx dx`
     - `b_n = (1/π)∫_{−π}^{π} f(x)sin nx dx`
  3. 写收敛结果（**在间断点处收敛到左右极限的平均值**）。
- **陷阱**：
  - 系数前的 `1/π`、`1/l` 系数丢（周期为 2l 时是 `1/l`）。
  - **间断点的和值写错**（要用 `(f(x₀⁻)+f(x₀⁺))/2`）。
  - 奇偶性没利用，白算一堆积分。
- **常考形式**：期末下册必考；考研数一考。

## 级数-敛散性中的参数讨论

- **触发特征**：题目含参数 `p`、`k`、`a`，问"当……时收敛"。
- **标准流程**：
  1. 判断型、找等价无穷小定阶。
  2. 按参数分情况（通常与 p 级数比较）。
  3. 列出收敛的参数范围。
- **陷阱**：
  - **区间端点归属搞错**（`p>1` 还是 `p≥1`）。
  - 只给结论不讨论边界情形。
- **常考形式**：考研数一/三高频。
