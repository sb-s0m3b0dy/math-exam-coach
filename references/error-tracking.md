## 完整 schema

文件：`<工作区根>/study/records/questions.md`


字段定义：

| 字段 | 取值 | 说明 |
|---|---|---|
| `编号` | `Q` + 递增数字 | 永不复用，退役也保留 |
| `首见日期` | `YYYY-MM-DD` | 第一次做错的日期 |
| `来源` | 自由文本 | 习题册 P42 / 期末真题 2023 / 老师 ppt 第 7 页 |
| `题面` | 一句话，可含 LaTeX | **必填**。题目的简短形式（如 `∫ x·arctan x dx`）。视图里的「题面」取这一列；不要在手写视图时另编 |
| `章节` | 与课程目录一致 | 便于按章复习，也是 time-planner 的输入 |
| `题型家族` | 见下表 | **同一个家族用完全相同的字串**，否则统计会碎掉 |
| `错误触发` | 短句 | 什么条件会让你走错路（"含根号就无脑平方"） |
| `错因` | 五选一（见错因分类） | 方法选错 / 概念不清 / 计算失误 / 前提遗漏 / 规范问题 |
| `正确触发` | 可执行动作 | 下次看到什么信号做什么（禁止"细心一点"） |
| `预计时长` | `Nmin` | 这道题达标需要的时间预算 |
| `连对次数` | 整数 | 连续限时达标次数；中断归零 |
| `退役阈值` | 2–4，默认 3 | 用户可调 |
| `限时记录` | `MM-DD Nmin ✓/✗`，可多段 | 每次限时重做的记录 |
| `下次复习` | `YYYY-MM-DD` 或 `-` | 由调度算法算；退役后为 `-` |
| `状态` | `在练` / `已退役` | |

## 错因分类（五类，不要自创）

| 类别 | 判据 | 处方 |
|---|---|---|
| 方法选错 | 知道概念但选了不合适的路 | 讲识别特征 + 交错练同类 |
| 概念不清 | 定义/定理条件说不上来 | 回讲概念 + 工作示例 |
| 计算失误 | 方法对，某步算错 | 只练计算准确性 + 检查动作，不重讲方法 |
| 前提遗漏 | 漏定义域、漏讨论、漏条件 | 建立"先写定义域"的固定动作 |
| 规范问题 | 跳步、答语不完整、格式 | 对照评分点改写法 |

**归因以用户重做后自己认下的为准。** AI 初判写进 `错误触发` 当候选，用户否定就改。

## 调度算法

排复习点时按以下规则（优先级从上到下）：

1. **有考试日期** → 从考试日**倒推**，保证每个到期项在考前至少过 2 遍。倒推不够排时，优先保 `方法选错`（这类最致命）。
2. **连对次数 0（新错题或刚归零）** → 间隔 1 天，再做错则**缩短到次日**并回②。
3. **连对次数 1** → 间隔 3 天。
4. **连对次数 2** → 间隔 7 天。
5. **连对次数 ≥ 退役阈值** → 退役，`下次复习` 置 `-`，不排。
6. **间隔宁长勿短**：如果用户表现出已经掌握（限时内轻松做对），下一间隔取更长档（1→3→7→21），不要因为"保险"排密。
7. **一次会话最多复习 6–10 道**，超出的按 `章节` 聚合，不要一次性堆完。

`下次复习` 的计算：**下一次复习日期 = 最近一次限时重做的日期 + 该次结果决定的间隔**。

- 「最近一次」指 `限时记录` 里**最后一段**的日期，不是 `首见日期`。
- 所以用户拖延（该 07-13 复习却拖到 07-15）之后，整个节奏跟着后移，不是"补一次计划里的那天"。
- 复习当时若做对，`连对次数` 加 1 后再查间隔档；若做错，先归零再取 1 天档。

举例（与上面的 Q001 对应）：07-12 首次做错（`连对次数` 0）→ 07-15 限时做对（`连对次数` 变 1）→ 间隔 3 天 → `下次复习` = 07-18。

## 退役规则

- 连续 `退役阈值` 次**限时达标**（时长 ≤ `预计时长` 且做对）→ 退役。
- **中断一次**（做错或超时）→ `连对次数` 归零，`下次复习` 缩到次日或 3 日内。
- 退役的题**不删除**，保留在文件中；考前可用它快速扫一遍（"退役题速览"）。
- 同一`题型家族`若出现 ≥2 道在练错题 → 该家族视为薄弱，优先排。

## 生成错题本视图

`study/错题本.md` 由 `questions.md` 生成，**按日期分组、最新在上**：

```markdown
# 错题本

最后更新：2026-07-15

## 2026-07-15

### Q003 · 积分-分部 · 计算失误
- 原题：∫ x·arctan x dx
- 错误触发：看到 arctan 就想换元
- 正确触发：先看哪个因子求导变简单，arctan 求导是有理式
- 限时记录：07-15 6min ✗
- 下次复习：2026-07-16
- 在练

## 2026-07-12
...
```

生成时按 `首见日期` 倒序分组；同一天内按编号升序。每条的字段从状态源取，不要另编。

## 导出

- 生成 `study/导出/错题本-YYYY-MM-DD.md`，**不覆盖**已有文件（同日重复导出加序号）。
- 若工作区已装 pandoc 等转换工具才转 PDF/Word；否则用 VS Code 打开 Markdown 预览另存。
- **不要**声称导出会"自动同步"到哪里。
- 导出前检查是否含个人信息（若用户要把文件发给别人）。

## 并发写

助手、多个设备、多个标签页可能同时改同一文件：

1. 写前**先读**当前内容。
2. **只追加/更新行**，不重排已有行。
3. 冲突时保留较新版本，但**两行都留**并标注 `（冲突待合并）`。
4. 不要静默覆盖——用户的数据丢失比文件不整齐严重得多。
