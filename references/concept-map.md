# 概念依赖与易混点

## 依赖图（学不下去时用来定位缺口）

```
实数与函数
 └─ 极限（定义 → 计算）
     ├─ 连续
     │   └─ 闭区间连续函数性质（零点/介值/最值）
     └─ 导数
         ├─ 微分
         ├─ 中值定理 ← 需要"闭区间连续+开区间可导"
         │   └─ 洛必达法则 ← 需要柯西中值定理
         └─ 泰勒公式 ← 需要高阶导数
             └─ 泰勒展开求极限
积分
 ├─ 原函数与不定积分 ← 需要导数公式表
 │   ├─ 换元 ← 需要复合函数求导
 │   ├─ 分部 ← 需要乘积求导
 │   └─ 有理函数积分 ← 需要部分分式
 └─ 定积分 ← 需要"极限求和"
     ├─ 变限积分求导 ← 需要复合函数求导
     ├─ 反常积分 ← 需要极限
     └─ 定积分应用 ← 需要几何直觉
多元
 └─ 偏导数 ← 需要一元导数
     ├─ 全微分
     ├─ 隐函数 ← 需要链式法则
     ├─ 极值 ← 需要一元极值
     └─ 重积分 ← 需要定积分 + 换元（雅可比）
级数
 ├─ 数项级数 ← 需要极限 + 比较
 │   └─ 绝对值 → 绝对/条件收敛
 └─ 幂级数 ← 需要数项级数 + 泰勒
     └─ 傅里叶 ← 需要三角函数正交性
微分方程
 └─ 一阶 ← 需要积分
     └─ 二阶 ← 需要特征方程（代数）
```

**用法**：用户在某处反复出错时，**顺箭头往回找**最早断裂的那一环。例如"泰勒求极限总是错" → 可能是"高阶导数"或"泰勒公式本身"没掌握，不是极限的问题。

## 易混概念对照

| A | B | 区别 |
|---|---|---|
| 可去间断点 | 跳跃间断点 | 左右极限是否相等 |
| 极值点 | 最值点 | 局部 vs 整体；端点可能是最值但通常不是极值 |
| 驻点 | 极值点 | 驻点是 f′=0，不一定是极值（x³）；极值点可能不可导（\|x\|） |
| f″=0 | 拐点 | 拐点要求 f″ 变号 |
| 凹 | 凸 | **教材约定不同，先确认课本**（同济：f″>0 为凹/下凸） |
| 第一类曲线积分 | 第二类 | 与方向是否有关 |
| 第一类曲面积分 | 第二类 | 与侧是否有关 |
| 绝对收敛 | 条件收敛 | Σ\|u_n\| 是否收敛 |
| 收敛 | 和存在 | 对级数是一回事，对数列要区分 |
| 偏导存在 | 可微 | 偏导存在不一定可微；可微一定偏导存在 |
| 梯度 grad | 散度 div | grad 作用于标量→向量；div 作用于向量→标量 |
| 散度 div | 旋度 rot | div 结果标量；rot 结果向量 |
| 格林公式 | 高斯公式 | 平面闭曲线 vs 空间闭曲面 |
| 通解 | 特解 | 通解含任意常数 |
| 齐次方程 | 齐次线性方程 | "齐次"在这两处含义完全不同（一次 vs 无常数项） |

## 三个最常见的"记反了"

1. **p 判别法方向**：`∫_1^∞ 1/x^p` 要 `p>1`；`∫_0^1 1/x^p` 要 `p<1`。（无穷处要"衰减更快"，瑕点处要"发散更慢"）
2. **等价无穷小不能用在加减**：`sin x − x` 不能换成 0。
3. **二阶参数方程求导要除以 x′(t)**：`d²y/dx² = (d/dt(y′/x′))/x′`。

这三条如果能默写出来并解释为什么，就已经避开了高数失分的一大块。
