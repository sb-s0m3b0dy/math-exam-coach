# 题型库：函数、极限、连续

## 极限-等价无穷小替换

- **触发特征**：
  - 分母/分子是单项式（`x`、`x²`、`sin x`、`1−cos x`）
  - 出现 `sin x`、`tan x`、`arcsin x`、`arctan x`、`ln(1+x)`、`e^x−1`、`1−cos x`、`(1+x)^α−1`
  - 整个式子能化成**乘积或商的因子**结构
- **标准流程**：
  1. 先判断型（0/0、∞/∞、0·∞、∞−∞、1^∞）。
  2. 把式子拆成**因子的乘积/商**。
  3. 只对因子用等价替换，**等价替换不能用在加减项上**（除非两个替换量阶数相同且可以整体提出）。
  4. 替换后化简，若还是 0/0 则换泰勒。
- **陷阱**：
  - 在**加减**里用等价替换（`sin x − x` 直接换掉是错的，结果是 0 而非 −x³/6）。
  - `1−cos x ~ x²/2` 忘掉系数，只写 `~x²`。
  - `x→0` 的条件没验证就开始换（如本质是 `x→∞`）。
- **常考形式**：期末填空/选择；考研客观题（几乎每年）。常配一道需要"先分离出乘积结构"的变形题。

## 极限-泰勒展开

- **触发特征**：
  - 分母是 `x^k`（`x²`、`x³`、`x⁴`），分子含超越函数
  - 分子是**同阶量相减**（`e^x − 1 − x`、`sin x − x`、`ln(1+x) − x`）
  - 等价无穷小替换后仍是 0/0
- **标准流程**：
  1. **看分母的阶数 k，分子就展到 k 阶**（这是判据，不是"多展几项保险"）。
  2. 逐项展开（常用：`e^x`、`sin x`、`cos x`、`ln(1+x)`、`(1+x)^α`、`arctan x`、`tan x`）。
  3. 抵消低阶项，保留到 k 阶，写出 `o(x^k)`。
  4. 相除得极限。
- **陷阱**：
  - 展开阶数不够（分母 x³ 却只展到 x²）→ 结果错或算不出来。
  - 忘写余项 `o(x^k)`，在需要抵消时无法判断。
  - 加减法里分别展开后**丢掉高阶余项的相对大小**判断。
- **常考形式**：`lim_{x→0}(e^x−1−x)/x² = 1/2` 这类极限题的标准解法；考研数一/二大题常用的第一步。

## 极限-洛必达

- **触发特征**：
  - 0/0 或 ∞/∞，且分子分母**都可导**
  - 分子分母含 `ln x`、`e^x`、`arctan x` 等求导后变简单的函数
- **标准流程**：
  1. **先验证条件**：必须是 0/0 或 ∞/∞。
  2. 分子分母分别求导（不是商的求导法则）。
  3. 检查新极限是否存在（存在才有效，不存在不能反推原极限不存在）。
  4. 可多次使用，但**每次都要重新验证型**。
- **陷阱**：
  - 条件是 `1/0` 或 `0·∞` 时直接用（不满足）。
  - 用洛必达时**没化到 0/0 或 ∞/∞ 就求导**。
  - 分母有 `x²` 时用洛必达要三次，比泰勒慢得多——**这是最常见的低效选择**。
  - `lim (x+sin x)/x` 这类能直接拆的题硬用洛必达。
- **常考形式**：期末大题常见但通常有更快的路；考研中作为"陷阱选项"出现。

## 极限-夹逼

- **触发特征**：
  - 含 `n` 项和的极限（`Σ` 且项数随 n 变）
  - 含取整函数 `[x]`、`{x}`
  - 含 `n` 次根号的复杂表达式
  - 无法直接求出闭合形式的和
- **标准流程**：
  1. 找出表达式的**界**（最大值/最小值项，或 1/n 的放缩）。
  2. 构造两个可求极限的夹逼函数。
  3. 验证两端极限相等。
  4. 中间极限等于该值。
- **陷阱**：
  - 放缩过头（一端极限不存在或不等）。
  - `Σ_{k=1}^n` 型忘了它可以写成**定积分定义**（`(1/n)Σf(k/n) → ∫₀¹f`），那是另一条路。
- **常考形式**：期末证明题；考研数一大题固定考点之一。

## 极限-单调有界

- **触发特征**：
  - 递推数列 `a_{n+1} = f(a_n)`
  - 题目问"证明极限存在并求极限"
- **标准流程**：
  1. **先猜**极限值（假设 `a_n → a`，解 `a = f(a)`）。
  2. 证明有界（常用数学归纳法）。
  3. 证明单调（作差 `a_{n+1} − a_n` 或作商，定符号）。
  4. 由单调有界准则得极限存在，再由递推式取极限解得值。
- **陷阱**：
  - **直接对递推式两边取极限**（循环论证，必须先用准则证明存在）。
  - 只证有界不证单调，或反之。
  - 猜出的极限有多个解时没排除。
- **常考形式**：期末/考研证明题经典。数一数二都常考。

## 极限-无穷小的比较

- **触发特征**：问"是几阶无穷小""同阶/高阶/等价"
- **标准流程**：
  1. 求 `lim (α/β)`。
  2. 结果为 0 → 高阶；∞ → 低阶；非零常数 c → 同阶（c=1 则等价）；不存在 → 不可比较。
- **陷阱**：把"高阶"和"更大"混（高阶无穷小反而**更小**）。
- **常考形式**：期末选择/填空；考研客观题。

## 连续-间断点分类

- **触发特征**：给分段函数问间断点类型
- **标准流程**：
  1. 找出无定义点/分段点。
  2. 求左右极限。
  3. 左右极限存在且相等但不等于函数值（或函数无定义）→ 可去间断点。
  4. 左右极限存在但不等 → 跳跃间断点。
  5. 至少一侧不存在 → 第二类（无穷/振荡）。
- **陷阱**：
  - 漏掉**分段点本身**（哪怕函数在那里有定义，也要查左右极限是否等于函数值）。
  - 把"可去"和"跳跃"混。
- **常考形式**：期末必考小题。

## 连续-闭区间上连续函数的性质

- **触发特征**：题目问"证明存在 ξ 使 f(ξ)=0"或"证明有界/能取到最大最小值"
- **标准流程**：
  1. 验证**闭区间**上连续。
  2. 零点定理：端点异号 → 存在零点（可反复二分）。
  3. 介值定理：任意值在两端之间都能取到。
  4. 有界性/最值定理：连续 → 有界、能取到最值。
- **陷阱**：
  - 区间**不是闭区间**就用最值定理。
  - 端点值符号判断错误。
- **常考形式**：期末证明题入门；考研与中值定理结合出。
