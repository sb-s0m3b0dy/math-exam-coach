# 题型库：导数与微分、微分中值定理

## 导数-隐函数求导

- **触发特征**：方程 `F(x,y)=0` 形式给出 y 与 x 的关系，问 `y'` 或 `dy/dx`。
- **标准流程**：
  1. 两边对 x 求导，**把 y 看成 x 的函数**（含 y 的项要乘 `y'`）。
  2. 解出 `y'`。
  3. 若要求某点的导数值，先由原方程求出该点的 y，**再代入**。
- **陷阱**：
  - 忘记对 y 项乘 `y'`。
  - 直接把 x 的值代入而不先求对应的 y。
  - 对数求导法（含 `y^x` 或连乘连除）忘了取对数。
- **常考形式**：期末大题；考研客观题常配参数方程一起考。

## 导数-参数方程求导

- **触发特征**：`x=x(t), y=y(t)`，问 `dy/dx` 或二阶导。
- **标准流程**：
  1. `dy/dx = (dy/dt)/(dx/dt)`（要求 `dx/dt ≠ 0`）。
  2. 二阶导：`d²y/dx² = d(dy/dx)/dt ÷ (dx/dt)`。
- **陷阱**：
  - 二阶导**直接对 `dy/dx` 再求一次 t 的导数**（漏除以 `dx/dt`）。
  - 反函数求导公式记反。
- **常考形式**：期末必考；考研高频。

## 导数-高阶导数

- **触发特征**：问 `f^(n)(x)` 或某点的 n 阶导。
- **标准流程**：
  1. 求前 3–4 阶找规律。
  2. 常用：莱布尼茨公式（乘积）、有理分式部分分式后逐项求导、三角/指数函数周期性。
  3. 归纳出通式，用数学归纳法验证。
- **陷阱**：
  - `(uv)^(n)` 用成 `u^(n)v^(n)`（莱布尼茨是**求和**）。
  - 有理函数不先部分分式就硬求。
- **常考形式**：期末；考研数一偶出大题。

## 导数-切线与法线

- **触发特征**：问"切线方程""法线方程"。
- **标准流程**：
  1. 求 `f'(x₀)` 作为斜率。
  2. 点斜式写切线：`y − y₀ = f'(x₀)(x − x₀)`。
  3. 法线斜率是 `−1/f'(x₀)`（`f'(x₀)=0` 时法线竖直）。
- **陷阱**：
  - 曲线由隐函数/参数方程给出时，用 `x₀` 直接代错 y。
  - `f'(x₀)=0` 时法线写成 `−1/0`。
- **常考形式**：期末小题，与几何应用结合。

## 导数-单调性与极值

- **触发特征**：问单调区间、极值、"证明不等式"。
- **标准流程**：
  1. 求定义域。
  2. 求 `f'`，找驻点与不可导点。
  3. 列表判断 `f'` 符号 → 单调区间与极值。
- **陷阱**：
  - 忘记**定义域**先于一切（如 `ln x` 只在 x>0）。
  - 只找驻点，漏掉**不可导点**（如 `|x|` 在 0）。
  - `f'(x₀)=0` 一定是极值（错，如 x³ 在 0）。
- **常考形式**：期末大题；考研常与中值定理结合证明不等式。

## 导数-凹凸性与拐点

- **触发特征**：问凹/凸区间、拐点、渐近线（作图题）。
- **标准流程**：
  1. 求 `f''`。
  2. `f''>0` 凹（下凸），`f''<0` 凸（上凸）。
  3. 拐点：`f''` 变号点（二阶导为 0 不一定是拐点）。
- **陷阱**：
  - 凹/凸定义方向记反（**先确认教材约定**，同济教材的凹向上对应 f''>0）。
  - 只看 `f''=0` 不看变号。
- **常考形式**：期末作图题；考研较小。

## 导数-微分中值定理证明

- **触发特征**：
  - 题目含"存在 ξ 使 f'(ξ)= ..."
  - 含"证明存在一点满足某等式"
  - 给出了 `f(a)=f(b)` 或类似条件
- **标准流程**：
  1. **先辨型**：罗尔（端点相等）/ 拉格朗日（一般）/ 柯西（两个函数之比）。
  2. 写清**在闭区间连续、开区间可导**的条件。
  3. 构造辅助函数（把要证的结论整理成 `g'(ξ)=0` 形式）。
  4. 对 g 用罗尔定理。
- **陷阱**：
  - **辅助函数构造不出来**（关键技能，需要把结论里的 ξ 换成 x 再积分构造）。
  - 没验证定理条件就用。
  - 需要**两次使用**中值定理时找不出两个区间。
- **常考形式**：期末压轴；考研数一/二必考大题（拉格朗日 + 构造辅助函数）。
- **辅助函数构造法**：
  - 要证 `f'(ξ) + g(ξ)f(ξ) = 0` → 用 `e^{∫g}` 作为乘子。
  - 要证 `f'(ξ) = f(ξ)/ξ`-型 → 构造 `f(x)/x`。
  - 要证含两个中值点 → 分两个区间分别用。

## 导数-不等式证明

- **触发特征**：证明 `f(x) ≥ g(x)` 在某区间成立。
- **标准流程**：
  1. 移项构造 `F(x) = f(x) − g(x)`。
  2. 求 `F'`，定单调性。
  3. 判 `F(端点)` 的符号。
  4. 若单调性不足，求 `F''` 或考虑构造函数二阶。
- **陷阱**：
  - 只证一个端点就下结论。
  - 需要**分段讨论**时只做一段。
- **常考形式**：期末；考研大题常见。

## 导数-方程根的个数

- **触发特征**：问"方程有几个实根"。
- **标准流程**：
  1. 构造 `f(x)`，求 `f'` 找单调区间与极值。
  2. 讨论各极值点符号与无穷远处趋势。
  3. 结合介值定理数根。
- **陷阱**：漏讨论定义域边界与极限趋势。
- **常考形式**：期末大题的固定小问；考研客观题。
