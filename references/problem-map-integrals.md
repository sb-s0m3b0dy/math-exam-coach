# 题型库：不定积分、定积分、反常积分、应用

## 积分-换元

- **触发特征**：
  - 被积函数是复合函数 `f(g(x))g'(x)` 形式
  - 含根号：`√(a²−x²)`、`√(x²+a²)`、`√(x²−a²)`
  - 出现 `x² + a²` 或 `a² − x²` 在分母
- **标准流程**：
  1. **第一类**（凑微分）：把 `g'(x)dx` 凑成 `dg(x)`，令 `u=g(x)`。
  2. **第二类**（三角代换）：
     - `√(a²−x²)` → `x = a sin t`
     - `√(a²+x²)` → `x = a tan t`
     - `√(x²−a²)` → `x = a sec t`
  3. 求完**必须换回 x**（用直角三角形辅助）。
  4. 定积分用换元时**上下限要一起换**。
- **陷阱**：
  - 定积分换元后**没换上下限**（最高频错误）。
  - 三角代换后忘换回原变量。
  - 结果忘了 `+C`（不定积分）。
- **常考形式**：期末/考研必考。数二每年一道大题。

## 积分-分部

- **触发特征**：
  - **乘积**形式：`x·e^x`、`x·sin x`、`x·ln x`、`x·arctan x`、`ln x`、`arcsin x`
  - 反三角函数、对数函数单独出现（不能用换元时）
- **标准流程**：
  1. `∫u dv = uv − ∫v du`。
  2. **选 u 的顺序（反对幂指三）**：反三角 > 对数 > 幂函数 > 指数 > 三角。（靠后当 dv）
  3. 判据：**选谁当 u，就看它求导后是否变得更简单**。
  4. 有时需要**两次分部**后解方程（`∫e^x sin x dx` 型）。
- **陷阱**：
  - u 选反（选 `e^x` 当 u，越做越复杂）。
  - 两次分部后**没移项解出原积分**。
  - `∫ln x dx` 不会"把 ln x 当 u，dx 当 dv"。
- **常考形式**：期末/考研高频大题。

## 积分-有理函数

- **触发特征**：被积函数是两个多项式的商。
- **标准流程**：
  1. **假分式先做多项式除法**（分子次数 ≥ 分母次数）。
  2. 分母因式分解。
  3. 部分分式分解（每个因式对应一个待定系数项；重因式要写多层）。
  4. 逐项积分（`A/(x−a)` → `A ln|x−a|`；`(Ax+B)/(x²+px+q)` → 配方后 arctan/ln）。
- **陷阱**：
  - **假分式不先除法**，直接部分分式（错）。
  - 重因式漏写次高项（`(x−a)²` 要写 `A/(x−a) + B/(x−a)²`）。
  - 忘绝对值在 ln 里。
- **常考形式**：期末大题；考研数一/二常考。

## 积分-三角有理式

- **触发特征**：被积函数是 sin、cos 的有理式。
- **标准流程**：
  1. **万能代换** `t = tan(x/2)` 一定可行但常很繁。
  2. 更优选：
     - `R(−sin x, cos x) = −R` → 令 `u = cos x`
     - `R(sin x, −cos x) = −R` → 令 `u = sin x`
     - `R(−sin x, −cos x) = R` → 令 `u = tan x`
  3. 有时先用倍角公式化简。
- **陷阱**：一上来就用万能代换，把简单的题做复杂（这是"能做出来但浪费时间"的典型）。
- **常考形式**：期末；考研偶出。

## 积分-定积分性质

- **触发特征**：被积函数有对称性、周期性；或上下限特殊（0 到 π、−a 到 a）。
- **标准流程**：
  1. 查奇偶性：奇函数在对称区间积分为 0；偶函数为 2 倍半区间。
  2. 周期性：整周期上积分相等。
  3. 区间再现公式：`∫₀^a f(x)dx = ∫₀^a f(a−x)dx`（处理 `∫₀^{π/2} sin x/(sin x+cos x) dx` 型）。
  4. 利用 `∫₀^{π} x f(sin x) dx = (π/2)∫₀^{π} f(sin x)dx` 型公式。
- **陷阱**：
  - 区间不对称（如 0 到 2）就想用奇偶性。
  - 被积函数在区间内有瑕点却没发现（变成反常积分）。
- **常考形式**：期末/考研大题的"巧解"考点。

## 积分-反常积分收敛性

- **触发特征**：
  - 积分上限/下限是 ∞
  - 被积函数在积分区间内部或端点**无界**（分母为 0）
  - 题目问"判断收敛性"或"问 k 取什么值时收敛"
- **标准流程**：
  1. **先找瑕点**（分母为零的点）与无穷限——这决定了要不要拆区间。
  2. 拆成多个只含一个奇点的积分，**每个都必须收敛**才收敛。
  3. 用比较判别法：
     - `∫_1^∞ 1/x^p dx` 收敛 ⟺ `p > 1`
     - `∫_0^1 1/x^p dx` 收敛 ⟺ `p < 1`
  4. 找等价无穷小/无穷大定阶（用泰勒或等价替换）。
- **陷阱**：
  - **漏找瑕点**（如 `∫_0^1 1/(x−1)² dx` 里 x=1 是瑕点，容易忽略）。
  - 比较的**方向反了**（大收敛推小收敛，小发散推大发散——这个方向才对）。
  - `p` 判别法在 ∞ 与瑕点处**条件相反**（1/∞ 要 p>1；瑕点要 p<1），最容易记混。
- **常考形式**：期末必考；考研数一必考（含参数讨论）。

## 积分-定积分应用（面积体积）

- **触发特征**：求面积、旋转体体积、弧长、侧面积。
- **标准流程**：
  1. 画草图，定积分区间与被积函数（**上减下**、**右减左**）。
  2. 旋转体体积：
     - 绕 x 轴：`V = π∫ y² dx`
     - 绕 y 轴（柱壳法）：`V = 2π∫ x·|y| dx`
  3. 弧长：`s = ∫√(1 + y'²)dx`（直角坐标）/ 参数式 / 极坐标三套公式。
- **陷阱**：
  - 绕 y 轴时选错方法（柱壳 vs 圆盘），导致积分变得很难算。
  - 区间内函数**变号**时没分段。
  - 两条曲线的交点没求全。
- **常考形式**：期末大题必考；考研数二高频。

## 积分-变限积分求导

- **触发特征**：`F(x) = ∫_{a(x)}^{b(x)} f(t)dt`，问 `F'` 或求极限。
- **标准流程**：
  1. `F'(x) = f(b(x))b'(x) − f(a(x))a'(x)`。
  2. 若被积函数含 x（`∫ f(x,t)dt`），先把 x 提出或换元。
  3. 常与洛必达/泰勒结合求极限。
- **陷阱**：
  - 忘记乘以 `b'(x)`、`a'(x)`。
  - 被积函数里有 x 时直接套公式（错）。
- **常考形式**：期末/考研高频，是极限题的常见载体。
