# 轨道：大学高数期末 / 同步学习（默认）

## 适用

- 大学《高等数学》期末考（同济上下册体系）
- 平时跟着课程同步学、想当下就搞懂

用户没特别说明时**默认走这条轨道**。

## 期末考的结构（典型）

| 题型 | 题量 | 分值占比 | 难度特征 |
|---|---|---|---|
| 选择 | 5–8 | 20–30% | 概念辨析、计算 |
| 填空 | 5–8 | 20–30% | 纯计算，快速 |
| 计算 | 4–6 | 30–40% | 标准流程题 |
| 证明 | 1–2 | 10–20% | 中值定理/不等式 |
| 应用 | 1–2 | 10% | 几何/物理建模 |

**上册重点**：极限、导数、中值定理、不定积分、定积分及应用。
**下册重点**：多元微分、重积分、曲线曲面积分（依专业）、级数、微分方程。

## 期末的策略重点

1. **范围明确 → 不要求全**。期末考纲窄，把老师划定的题型刷透比广撒网有效得多。
2. **计算题是基本盘**。期末计算题占比最高且最容易通过练习拿满，优先保证。
3. **证明题只抓两类**：中值定理（罗尔/拉格朗日构造辅助函数）和不等式证明（移项求导）。其他证明题投入产出比低。
4. **老师讲过的例题 = 高概率原题变体**。让用户把课上例题整理出来，作为优先练习集。

## 按时间倒推的复习安排

有考试日期时这样排（技能自动执行）：

| 距考试 | 重点 |
|---|---|
| > 4 周 | 按章节补齐概念缺口，不刷套卷 |
| 2–4 周 | 分章节专项 + 错题本首轮复习 |
| 1–2 周 | 真题/模拟卷限时训练，2–3 天一套 |
| 3–7 天 | 只复习错题本 + 薄弱题型，不再学新内容 |
| 考前 1–2 天 | 扫 `已退役` 题 + 公式表 + 易错点清单 |

**考前一周不要再学新题型**，收益极低且增加焦虑。这是明确建议，不是可选项。

## 同步学习模式（无固定考试）

- 每次只处理**当周课上的内容**。
- 讲完立刻做 3–5 道交错题（含 1–2 道上周的，制造间隔）。
- 错题照常登记，复习点自动排（1/3/7/21 骨架可用）。

## 期末特有的"应试小动作"

这些不是数学内容，但对分数影响直接：

- 拿到卷子**先扫一遍全部题**，把最有把握的题目标出来先做。
- 计算题**写清步骤**（哪怕结果错，步骤分很值钱）。
- 定义域、分类讨论**写在最前面**（阅卷老师先看这个）。
- 留最后 10 分钟**专门检查**：符号、绝对值、+C、上下限、最终答案是否回答所问。
- 时间分配：按分值比例，不要在某一道题上死磕超过 1.5 倍预算时间。

## 与用户对话时的姿态

期末用户通常时间紧、压力大：

- **不要长篇大论**。讲了就练，练了就说错在哪。
- 用户说"就告诉我怎么做"时，走答案释放门控第 4 路（给答案 + 留痕），不要拖。
- 每次收尾给**明确的下一步**（"明天先做这三道反常用积分"），而不是泛泛的"继续努力"。
