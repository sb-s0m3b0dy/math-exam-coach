# 题型单元库（总索引）

这是本技能的核心资产：**题型的触发特征 → 标准流程 → 陷阱 → 常考形式**。

## 怎么用

看到一道题时，顺序是：

1. 先扫**触发特征**（题干里长什么样）→ 定题型家族。
2. 按**标准流程**走。
3. 对照**陷阱**检查自己有没有踩。
4. 用**常考形式**判断这题是"标准型"还是要变形。

**不要跳过第 1 步直接算。** 学生最大的失分点就在这里。

## 题型家族的命名纪律

`题型家族` 字段必须与 `references/error-tracking.md` 里那一节**逐字相同**。新增题型时先加到那一节，再在分册里写单元。

## 一个题型单元长什么样

```markdown
### 题型家族名
- **触发特征**：题干里出现什么就该想到它（列 2–4 条，含反例）
- **标准流程**：编号步骤
- **陷阱**：这张皮底下最常错的 2–4 条
- **常考形式**：期末怎么出、考研怎么出
```

写单元时宁少勿滥：**一个真正的触发特征胜过五条泛泛描述**。"含 xᵃ 与 eˣ 相乘"是好特征；"比较难"是废话。
