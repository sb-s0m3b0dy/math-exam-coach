# 题型库：空间解析几何、曲面积分（主要针对数一）

## 空间-向量运算

- **触发特征**：求向量夹角、垂直/平行、投影。
- **标准流程**：
  1. 夹角：`cos θ = (a·b)/(|a||b|)`。
  2. 垂直 ⟺ `a·b = 0`；平行 ⟺ `a×b = 0`（分量成比例）。
  3. `a` 在 `b` 上的投影：`(a·b)/|b|`。
  4. 面积：`|a×b|`；体积：`|(a×b)·c|`。
- **陷阱**：
  - 点积结果是**数**，叉积结果是**向量**，混用。
  - 投影是标量，投影向量还要乘 `b/|b|`。
- **常考形式**：期末下册；考研数一客观题。

## 空间-平面与直线

- **触发特征**：求平面方程、直线方程、位置关系。
- **标准流程**：
  1. 平面：点法式 `A(x−x₀)+B(y−y₀)+C(z−z₀)=0`，法向量由叉积得。
  2. 直线：点向式 `(x−x₀)/l = (y−y₀)/m = (z−z₀)/n`。
  3. 位置关系：
     - 线线：方向向量夹角，或解方程组。
     - 线面：`A·l + B·m + C·n = 0` ⟺ 平行（再看是否在面上）。
     - 面面：法向量关系。
- **陷阱**：
  - 直线写点向式时**方向向量有零分量**（需改用参数式）。
  - 判断"平行"后**没判断是否重合**。
- **常考形式**：期末下册必考；考研数一。

## 空间-曲面方程

- **触发特征**：识别/求柱面、锥面、旋转面。
- **标准流程**：
  1. 母线平行 z 轴的柱面：方程**不含 z**。
  2. 旋转面：把 `y²` 换成 `y²+z²`（绕 x 轴旋转时）。
  3. 锥面：母线过原点，判断齐次性。
- **陷阱**：旋转轴搞错，换错变量。
- **常考形式**：期末下册。

## 空间-曲线积分

### 第一类（对弧长）
- **触发特征**：`∫_L f(x,y)ds`，与方向**无关**。
- **标准流程**：参数化，`ds = √((dx/dt)²+(dy/dt)²)dt`。
- **陷阱**：上下限**从小到大**（第一类恒为正）。

### 第二类（对坐标）
- **触发特征**：`∫_L P dx + Q dy`，与方向**有关**。
- **标准流程**：
  1. 参数化直接算；
  2. 或用格林公式（封闭）；
  3. 或验证**路径无关**条件 `∂P/∂y = ∂Q/∂x`（单连通区域）后选简单路径。
- **陷阱**：
  - 第一类与第二类**搞混**（判断依据：有没有方向性）。
  - 换向时忘变号。
  - 路径无关条件要求**单连通**，有洞时不成立。
- **常考形式**：期末下册；考研数一必考。

## 空间-曲面积分

### 第一类（对面积）
- **触发特征**：`∬_Σ f(x,y,z)dS`。
- **标准流程**：投影到坐标面，`dS = √(1+z_x²+z_y²)dxdy`。
- **陷阱**：投影区域的上下片要分开（如球面投影分上下两半）。

### 第二类（对坐标）
- **触发特征**：`∬_Σ P dydz + Q dzdx + R dxdy`，与**侧**有关。
- **标准流程**：
  1. 化成 `∬ P(−z_x)+Q(−z_y)+R dxdy`（取上侧）——**一投二代三定号**。
  2. 或用高斯公式（封闭）：`∮∮ = ∭(P_x+Q_y+R_z)dV`。
  3. 不封闭时补面。
- **陷阱**：
  - **定向错误**（上侧/下侧决定正负号）。
  - 高斯公式要求**封闭且外侧**，且区域内有奇点时不能直接用。
  - 补面后**忘了减去补的那块**。
- **常考形式**：期末考试；考研数一必考大题。

## 空间-高斯公式与斯托克斯公式

- **触发特征**：
  - 高斯：封闭曲面的第二类曲面积分
  - 斯托克斯：空间闭曲线的第二类曲线积分
- **标准流程**：
  1. 高斯：`∮∮_Σ Pdydz+Qdzdx+Rdxdy = ∭_Ω (P_x+Q_y+R_z) dV`（Σ 取外侧）。
  2. 斯托克斯：`∮_L Pdx+Qdy+Rdz = ∬_Σ (rot F)·n dS`。
  3. 不合适时反向使用（把难算的曲面积分转成三重积分）。
- **陷阱**：
  - 方向/侧的规定（高斯外侧、斯托克斯与 L 的右手法则）。
  - 题目给的曲面**不封闭**却直接套高斯。
  - 加补面时符号处理。
- **常考形式**：考研数一必考大题。

## 空间-场论初步（数一）

- **触发特征**：求梯度、散度、旋度。
- **标准流程**：
  1. `grad u = (u_x, u_y, u_z)`。
  2. `div A = P_x + Q_y + R_z`（结果**是标量**）。
  3. `rot A = ∇×A`（结果**是向量**，按行列式展开）。
- **陷阱**：散度与旋度结果类型混淆。
- **常考形式**：考研数一客观题。
