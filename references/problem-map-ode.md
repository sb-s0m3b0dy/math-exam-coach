# 题型库：常微分方程

## 微分方程-可分离变量

- **触发特征**：能整理成 `dy/dx = f(x)g(y)`（x 与 y 能完全分开）。
- **标准流程**：
  1. 分离：`dy/g(y) = f(x)dx`。
  2. 两边积分。
  3. 解出通解；有初值条件时代入定 C。
- **陷阱**：
  - **除以 g(y) 时丢掉 `g(y)=0` 对应的常数解**（如 `y'=y` 时 y=0 也是解）。
  - 忘 `+C`，或 C 的位置写成 `e^C` 时没简化。
- **常考形式**：期末/考研基础题。

## 微分方程-一阶线性

- **触发特征**：能整理成 `y' + P(x)y = Q(x)` 的标准形式。
- **标准流程**：
  1. 化成标准形式（`y'` 系数为 1）。
  2. 套公式：`y = e^{−∫P dx}[∫Q e^{∫P dx}dx + C]`。
  3. 也可用积分因子法理解（乘 `e^{∫P dx}`）。
- **陷阱**：
  - **没先化成标准形式**（y' 前有系数时直接套）。
  - 公式里两个指数符号搞反（一个是 `−∫P`，一个是 `+∫P`）。
  - P、Q 里的负号丢失。
- **常考形式**：期末/考研必考，公式题。

## 微分方程-齐次型

- **触发特征**：能写成 `dy/dx = φ(y/x)`（分子分母同次）。
- **标准流程**：
  1. 令 `u = y/x`，则 `y = ux`，`y' = u + x u'`。
  2. 代入化成可分离方程。
  3. 解出 u，回代 `y = ux`。
- **陷阱**：
  - 忘了 `y' = u + xu'` 里的 `xu'` 项（直接写 `y'=u`）。
  - 回代时漏了 x。
- **常考形式**：期末；考研数一/二。

## 微分方程-伯努利方程

- **触发特征**：`y' + P(x)y = Q(x)y^n`（n≠0,1）。
- **标准流程**：
  1. 两边除以 `y^n`。
  2. 令 `z = y^{1−n}`，化为关于 z 的一阶线性。
  3. 解出 z 后回代。
- **陷阱**：忘了 `z'` 的系数是 `(1−n)`。
- **常考形式**：期末；考研数一/二偶出。

## 微分方程-二阶常系数齐次

- **触发特征**：`y'' + py' + qy = 0`，系数为常数。
- **标准流程**：
  1. 写特征方程 `r² + pr + q = 0`。
  2. 判别式 Δ>0：`y = C₁e^{r₁x} + C₂e^{r₂x}`。
  3. Δ=0：`y = (C₁ + C₂x)e^{rx}`。
  4. Δ<0（`r = α ± βi`）：`y = e^{αx}(C₁cos βx + C₂ sin βx)`。
- **陷阱**：
  - Δ=0 时忘记**乘 x**（写成 `C₁e^{rx}+C₂e^{rx}` 就重复了）。
  - Δ<0 时忘了 `e^{αx}` 因子。
  - β 取错（β 是虚部，不是根的模）。
- **常考形式**：期末/考研必考。

## 微分方程-二阶常系数非齐次

- **触发特征**：`y'' + py' + qy = f(x)`，f 是多项式/指数/三角或它们的乘积。
- **标准流程**：
  1. 先解对应齐次方程，得 `y_h`。
  2. 按 f 的形式设特解 `y*`：
     - `f = P_m(x)e^{λx}` → `y* = x^k Q_m(x)e^{λx}`（k 是 λ 作为特征根的重数：0/1/2）。
     - `f = e^{αx}(A cos βx + B sin βx)` → 类似，k 由 `α±βi` 是否为特征根决定。
  3. 代入求待定系数。
  4. 通解 = `y_h + y*`。
- **陷阱**：
  - **重数 k 判断错**（尤其是 λ 恰好是特征根时）。
  - 设特解时多项式的次数设低（f 是 m 次就设 m 次）。
  - 忘了通解要加 `y_h`。
- **常考形式**：期末/考研必考大题。

## 微分方程-应用题建模

- **触发特征**：文字题：衰变、温度冷却、种群增长、溶液浓度、几何条件。
- **标准流程**：
  1. 明确变量与变化率的关系（"变化率与当前量成正比"→ `dy/dt = ky`）。
  2. 列方程（可能含初值）。
  3. 解方程。
  4. **用实际意义检验**（浓度不能为负、种群不能无限）。
- **陷阱**：
  - 正负号（"以速率 a 减少"是 `dy/dt = −a`）。
  - 单位不统一。
- **常考形式**：期末大题；考研数一/二。
