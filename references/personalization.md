# 个性化档案

文件：`<工作区根>/study/00-learner.md`（游离态：无工作区时贴在对话里维护）

## 档案格式

**每行必须带来源标记**：`[明说]` / `[观察N次]` / `[推断]`。

```markdown
# 学习者档案

最后更新：2026-07-15

## 目标
- 目标考试：大学高数期末（上册+下册） [明说]
- 考试日期：2026-01-08 [明说]
- 计划后续：考研数学一 [明说]

## 水平基线
- 极限与导数基本可用，中值定理证明是弱项 [观察3次]
- 计算准确性一般，常丢符号 [观察5次]

## 表层偏好
- 详略：喜欢先看结论，再看推导 [明说]
- 语气：简洁，不要鼓励性套话 [明说]
- 符号：积分用 ∫ 不用 int [推断]
- 单次学习时长：40 分钟左右 [明说]
- 限时：要限时，但超过预算要提醒 [明说]
- 出题排序：优先按错题本到期项，其次新题型 [明说]

## 提醒与导出
- 导出格式：Markdown 即可 [明说]
- 会话内报到期项：要 [明说]
- 后台定时提醒：用 time-planner [明说]
```

## 可个性化的表层（封闭列表）

只允许调整这些，不要扩表：

1. 语气（简洁 / 温和 / 幽默）
2. 详略程度（结论优先 / 推导优先 / 均衡）
3. 符号与书写习惯
4. 例子偏好（生活场景 / 纯数学 / 物理背景）
5. 单次学习时长
6. 是否坚持"必须先自己作答"
7. 导出格式与位置
8. 提醒偏好（会话内 / 定时）
9. 出题排序（到期优先 / 章节顺序 / 交错）

## 不可改动的（骨架）

无论用户怎么要求都不要改：

- 五步法骨架本身
- 答案释放门控的**四路分支**（唯一例外：用户可要求放宽"主动索取答案必须留痕"这一条）
- 诊断与检验**必须由用户完成**（不能让 AI 自问自答代替）
- 归档结构（`study/` 布局与 `questions.md` 字段）
- 退役规则的**结构**（连续达标才退役、中断即归零）；`退役阈值` 的**数值**用户可调（2–4，默认 3）
- "先自己做再看答案"的默认设定

用户若坚持要改骨架，说明理由和代价，让他**明说**这个决定，然后记进档案（这是他的选择，不是默认）。

## 冲突规则

- **推断不得覆盖明说。** 冲突时 `[明说]` 永久优先，把 `[推断]` 那行删掉或标 `(已被明说覆盖)`。
- **明说项不可被推翻**：不能因为观察到几次不同表现就改掉他明说的偏好；要改先问他。
- 同一项每次会话**最多改一次**，避免来回横跳。
- 「观察N次」的 N 要写实际次数，不要写"多次"。

## 采集方式

**首次接触只问 3–5 个高影响问题**（不要一次问二十个）：

1. 目标考试是什么？考试日期？
2. 你觉得哪部分最弱？（再配一道诊断题验证）
3. 每天大概能投入多少时间？
4. 喜欢先看结论还是先看推导？
5. 要不要限时、要不要我主动报到期项？

其余从使用中累积：他每次说"太长了""直接说结论""这个符号我看不惯"都是在给档案信息——**当场记下来**，不要只在心里记。

## 回写规则

- 每次会话收尾时，把本次新观察写进档案（`最后更新` 日期改掉）。
- 只写**有证据**的：`[观察1次]` 可以，但别把一次偶然写成 `[明说]`。
- 档案要短。超过一屏就该合并同类项、删过时项。
- **不要依赖助手自带记忆当主状态源**：换设备、换会话、跨平台时记忆不保证在，`study/00-learner.md` 才是事实来源。每会话开始先读它。

## 与 time-planner 共享

同一工作区时，`study/00-learner.md` 两个技能共享（数学偏好与作息偏好在同一文件的不同小节）。分节写：`## 学习相关` / `## 作息相关`，互不覆盖。

若两技能分别装在两个工作区（各设备独立），各自维护自己的副本，不要求同步。
