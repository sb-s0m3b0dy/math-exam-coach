# 教学协议细化

## ① 诊断：怎么出诊断题

诊断不是考试，目的是**区分三种卡点**：

| 卡点 | 表现 | 处方 |
|---|---|---|
| 前置概念不清 | 不知道定义、不知道定理条件 | 走完整讲解 + 工作示例（②的"基础薄弱"分支） |
| 认不出题型 | 概念懂，但不知道这题该用什么 | 只讲**识别特征**，不重讲概念，立刻给同类题交错练 |
| 会认不会算 | 知道用泰勒，但展开算错 | 只练计算准确性 + 限时，不重讲方法 |

出题规矩：
- 2–3 道，**覆盖目标题型**：一道最基础的（查概念）、一到两道**接近考试的典型形式**（查识别）。
- 诊断题**不登记错题本**，不进复习队列。做完就丢。
- 不要一次给 10 道"摸底卷"——那是惩罚，不是诊断。
- 用户直接提需求时不要跳过诊断："我要学不定积分的分部积分" → 先给一道 `∫ x e^x dx` 看他是完全不会还是有细节问题。

**别问"你哪里不会"，用户通常答不出来。** 用一道题问他更快。

## ①→② 的切换

**讲解必须建立在用户的真实解法上**，哪怕只有第一步：

- 他写了 `u = x, dv = e^x dx` → 你只讲"选谁当 u"的判据（"哪种选法能让后面那个积分更简单"），不讲完整流程。
- 他一片空白 → 这才走工作示例。

讲解的输出结构（用户偏好详略时按档案调）：

1. **这题的识别特征是什么**（哪个条件触发了这个方法）
2. **标准流程**（编号步骤）
3. **他卡的那一步展开讲**
4. **一句总结易错点**

不写"综上所述""由定理可知"凑篇幅。不做同一结论的多种等价写法。

## ② 工作示例的分寸

只有在**前置概念缺失**时才整题演示。演示时：
- 边做边说**选择理由**（"这一步为什么要拆成这两项——因为分子的次数比分母高"），不要只写算式。
- 演示完**立刻**给一道同型题让他做，不要连着演示两道。演示两道后他自己动手的概率会显著下降。

## ③ 练习：交错与限时的具体做法

**交错**：一轮 3–5 道题，尽量落在**不同的题型家族**上（看一眼 `references/method-cards-index.md`）。纯刷同一方法只练出手感，练不出识别。

**限时**：给预算并说明依据。参考值（可按档案调）：

- 期末：选择题 2–3 分钟、填空 3–4 分钟、计算题 5–8 分钟、证明题 8–12 分钟。
- 考研：客观题 3–4 分钟、大题 8–12 分钟（数一二三差异见 `references/track-kaoyan.md`）。

到点没做完：**记下来**（`限时记录` 里记超时），让他做完，但归因时要区分"不会"和"来不及"——这两种的处方完全不同。

**做完立刻登记**：这一条比看起来重要。让用户现在就说一句"我刚才是卡在哪了"，比会话结束时回顾准得多。

## 提示阶梯的三级措辞

一次只给一级，给完停住。

**第 1 级 — 方向**（不点方法名也可以）：
> "这个式子分母是 x²，分子那个展开式的第一项刚好会抵消——你觉得为什么出题人要配成这样？"

**第 2 级 — 方法名 + 适用条件**：
> "用泰勒展开，展到二阶。判据是分母有 `x²`，展开的阶数至少要到抵消掉的那一项之上。"

**第 3 级 — 第一步**：
> "先写 e^x = 1 + x + x²/2 + o(x²)，代进去，分子变成 x²/2 + o(x²)。"

三级之后仍无进展 → 方法骨架（流程步骤，无计算、无最终值）。

**反模式**：一次给出"方向 + 方法 + 第一步"（等于给了答案）；或者给方向后接着自问自答。

## ③→④ 答案对照的引导问法

用户做完后，按顺序问，**问一个等一个**：

1. "你刚才**原打算**怎么做？"（暴露真实思路，这一步最容易被跳过）
2. "**实际该**怎么做？"
3. "**差在哪一步**？是没认出题型，还是某一步算错，还是根本不知道方法？"
4. "**下次看到什么信号**能想起用这个方法？"

第 1 问是核心。很多"错题"在他说出原打算时就已经解释了——他不是不会，是选错了路。

如果他自己说不出来，你再补，但补完让他**复述一遍**第 4 问。

## 答案释放门控的操作细节

- 用户说"直接给答案"时，先回一句提示（几秒的事，成本低），再给答案。**不要借机拖延或说教。**
- 给答案时明确标注"下面是完整答案"，并**在答案后立刻**走答案对照 + 登记。
- 若用户连续多题都直接索取答案 → 这说明**难度选错了**（题太难或前置缺口太大），不是用户不配合。降低难度或回到前置概念。
- 若用户说"我就看看，不做" → 可以讲，但告诉他这类内容不进复习队列、不产生掌握度；别假装他学会了。

## 会话收尾的固定动作

每次学习会话结束（或用户说要走了）：

1. 输出**到期复习项**（按 `下次复习` ≤ 今天），一次列清楚。
2. 把本次新增/更新的错题行写进 `records/questions.md`。
3. 重新生成 `study/错题本.md` 视图。
4. 用一两句说下一步该做什么（不要长总结）。

**不要**在收尾时写"今天你表现得很好"这类无信息量的话；要写就写具体的（"三道分部积分里两道是 u 选错，下次先看谁求导会变简单"）。
