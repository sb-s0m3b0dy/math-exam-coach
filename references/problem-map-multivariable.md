# 题型库：多元函数微分学、二重积分

## 多元-偏导数与全微分

- **触发特征**：问 `∂z/∂x`、全微分 `dz`、复合函数求偏导。
- **标准流程**：
  1. 求偏导时**把其他变量当常数**。
  2. 复合函数用链式法则画**变量关系树**，逐条路径相加。
  3. 全微分：`dz = z_x dx + z_y dy`。
- **陷阱**：
  - 复合函数漏路径（`z=f(u,v), u=u(x,y), v=v(x,y)` 容易漏项）。
  - 抽象函数记号 `f₁'` 与 `f₂'` 的代入点搞错。
- **常考形式**：期末/考研必考。

## 多元-隐函数求偏导

- **触发特征**：`F(x,y,z)=0` 确定 `z=z(x,y)`，问 `∂z/∂x`。
- **标准流程**：
  1. 公式：`∂z/∂x = −F_x/F_z`（`F_z ≠ 0`）。
  2. 或两边直接对 x 求偏导再解。
- **陷阱**：
  - **负号丢了**（公式里必有负号）。
  - 分母写成 `F_x`（应为 `F_z`）。
- **常考形式**：期末/考研高频。

## 多元-极值与拉格朗日乘数

- **触发特征**：
  - 求 `z=f(x,y)` 的极值 → 无条件极值
  - 有约束条件 `φ(x,y)=0` → 条件极值
- **标准流程**（无条件）：
  1. 解 `f_x=0, f_y=0` 求驻点。
  2. 令 `A=f_xx, B=f_xy, C=f_yy`。
  3. `AC−B²>0`：A>0 极小，A<0 极大；`AC−B²<0`：不是极值；`=0`：需另行判断。
- **标准流程**（条件极值，拉格朗日）：
  1. 构造 `L = f + λφ`。
  2. 解方程组 `L_x=0, L_y=0, L_φ=0`。
  3. 比较各候选点的函数值（**有界闭区域上还要查边界**）。
- **陷阱**：
  - `AC−B²>0` 时**忘看 A 的符号**判极大极小。
  - 条件极值忘了"有界闭区域要单独查边界"。
  - 拉格朗日方程组解不全（常需消元技巧）。
- **常考形式**：期末/考研必考（应用题：最大体积、最短距离）。

## 多元-二重积分直角坐标

- **触发特征**：给出积分区域 D，被积函数在直角坐标下简单。
- **标准流程**：
  1. **画区域图**（不画图基本必错）。
  2. 选 X 型（先 y 后 x）或 Y 型（先 x 后 y）。
  3. 定内外层上下限：**外层是常数，内层是函数**。
- **陷阱**：
  - 内层上下限写反（必须**上减下**）。
  - 外层写成函数（不能）。
  - 区域分块时漏块。
- **常考形式**：期末/考研必考。

## 多元-二重积分换序

- **触发特征**：
  - 题目给出先 y 后 x 的形式，但因为**原函数积不出来**必须换序
  - 含 `∫ e^{x²}dx`、`∫ sin(x²)dx`、`∫ (sin x)/x dx` 这类"积不出"的函数
- **标准流程**：
  1. 由原积分限写出区域 D 的不等式。
  2. 重新画图，按另一顺序描述 D。
  3. 写新的积分限。
- **陷阱**：
  - **区域描述错误**（这是换序题唯一难点，必须画图）。
  - 只看积分限不还原区域，直接"交换 dx dy"（错）。
- **常考形式**：期末/考研高频；识别特征就是"积不出来的函数"。

## 多元-二重积分极坐标

- **触发特征**：
  - 区域是圆/圆环/扇形
  - 被积函数含 `x²+y²`
  - 直角坐标下根号难处理
- **标准流程**：
  1. `x = r cos θ, y = r sin θ`，`dxdy = r dr dθ`。
  2. 定 r 的范围（从原点出发的射线穿过区域）。
  3. 定 θ 的范围。
- **陷阱**：
  - **忘乘雅可比 r**（最高频错误）。
  - r 的上下限写错（要先求交点）。
  - 区域含原点时 r 从 0 开始。
- **常考形式**：期末/考研必考。

## 多元-三重积分

- **触发特征**：空间区域上的积分。
- **标准流程**：
  1. 投影法（先一后二）：投影到 xOy 面，先对 z 积分。
  2. 截面法（先二后一）：固定 z 切片。
  3. 柱坐标 `dV = r dr dθ dz`；球坐标 `dV = r² sin φ dr dφ dθ`。
- **陷阱**：
  - 柱坐标忘乘 `r`；球坐标忘乘 `r² sin φ`。
  - 投影区域求错。
- **常考形式**：期末（下册）；考研数一。

## 多元-曲线积分与格林公式

- **触发特征**：
  - 沿曲线的积分 `∫_L P dx + Q dy`
  - 封闭曲线 + 格林公式
- **标准流程**：
  1. 判断 L 是否封闭、方向（格林公式取**正向**＝逆时针）。
  2. 封闭 → 格林公式：`∮P dx+Q dy = ∬(Q_x − P_y)dxdy`。
  3. 不封闭 → 补线（补成封闭再减去补线部分）或直接参数化。
  4. 检查区域内是否有**奇点**（P、Q 无定义点）——有则不能直接用格林，要挖洞。
- **陷阱**：
  - **方向搞反**（顺时针要加负号）。
  - 区域内有奇点却直接用格林（如 `∮ (x dy − y dx)/(x²+y²)` 在含原点时）。
  - 只考数一，数二数三不考。
- **常考形式**：期末下册；考研数一必考。
